# Configuration map

Defaults below are code defaults, not deployment recommendations. The
authoritative parsers are `controller/src/config/env.ts`,
`services/agent-runtime/src/data-dir.ts`, `settings-service.ts`,
`frontend/src/lib/api/connection.ts`, and Electron's `configs.ts`.

## Boundary and process variables

| Variable                                                                                                                | Set/read/default                                                                                                                                                      | Failure mode                                                                                           |
| ----------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `LOCAL_STUDIO_DATA_DIR`                                                                                                 | Electron injects its `userData`; controller and runtime both read it, but as separate stores. Controller defaults to repository `data`, runtime to `~/.local-studio`. | Wrong host/path splits or loses settings, sessions and controller DB.                                  |
| `LOCAL_STUDIO_AGENT_RUNTIME_URL`                                                                                        | Electron/start automation sets it; Next `proxy-to-runtime.ts` reads it; default `http://127.0.0.1:8081`.                                                              | Agent APIs reach the wrong runtime or return 502.                                                      |
| `LOCAL_STUDIO_FRONTEND_BASE`                                                                                            | Electron injects the Next URL; Pi extension helpers read it; default `http://127.0.0.1:3000`.                                                                         | Runtime callbacks/tools call the wrong frontend.                                                       |
| `BACKEND_URL` / `NEXT_PUBLIC_API_URL` / `NEXT_PUBLIC_BACKEND_URL` / `LOCAL_STUDIO_BACKEND_URL`                          | `shared/agent/backend-url.ts` and frontend connection resolution select controller defaults.                                                                          | UI/runtime target the wrong controller; note that runtime itself does not directly read `BACKEND_URL`. |
| `API_KEY`                                                                                                               | Runtime settings default only; frontend example also documents it.                                                                                                    | Missing controller auth until persisted; it is not runtime client auth.                                |
| `LOCAL_STUDIO_API_KEY`                                                                                                  | Controller server key in `config/env.ts`; frontend connection fallback in `connection.ts`.                                                                            | Required for non-loopback controller bind unless explicitly waived.                                    |
| `PORT`                                                                                                                  | runtime default 8081; production frontend launcher default 4783; injected per child.                                                                                  | Collision or wrong proxy target.                                                                       |
| `HOSTNAME`                                                                                                              | production Next launcher defaults `127.0.0.1`.                                                                                                                        | Changes frontend exposure. Agent runtime ignores it and hard-codes loopback.                           |
| `LOCAL_STUDIO_HOST` / `LOCAL_STUDIO_PORT`                                                                               | controller defaults `127.0.0.1:8080`.                                                                                                                                 | Controls controller exposure/reachability.                                                             |
| `LOCAL_STUDIO_INFERENCE_HOST` / `LOCAL_STUDIO_INFERENCE_PORT`                                                           | controller defaults `localhost:8000`.                                                                                                                                 | Controller cannot reach the inference engine.                                                          |
| `LOCAL_STUDIO_API_KEY`, `LOCAL_STUDIO_ALLOW_UNAUTHENTICATED`, `LOCAL_STUDIO_ALLOWED_HOSTS`, `LOCAL_STUDIO_CORS_ORIGINS` | decoded together by controller `createConfig`.                                                                                                                        | Unsafe or rejected non-loopback startup, Host rejection, or browser CORS failure.                      |
| `LOCAL_STUDIO_FRONTEND_TOKEN` / `LOCAL_STUDIO_FRONTEND_ALLOW_UNAUTHENTICATED`                                           | frontend access boundary, documented in `frontend/.env.example` and enforced by `frontend/src/lib/auth`.                                                              | Production frontend refuses startup/access or becomes intentionally unauthenticated.                   |
| `ALLOWED_TAILSCALE_HOSTS` / `ALLOWED_TAILSCALE_USERS`                                                                   | `frontend/src/proxy.ts`.                                                                                                                                              | Tailscale identity/host requests denied or over-broadly accepted.                                      |

Standard platform variables (`PATH`, `HOME`, `USER`, `LOGNAME`, `SHELL`,
`COMSPEC`, `APPDATA`, `LOCALAPPDATA`, `PROGRAMFILES`,
`PROGRAMFILES(X86)`, `XDG_CONFIG_HOME`, `SNAP`, `WSL_DISTRO_NAME`) only guide
executable, home, shell, platform, and application discovery. `NEXT_RUNTIME` is
set by Next and gates Node instrumentation.

## Important absent knobs

There is no agent-runtime host variable: `server.ts` always binds
`127.0.0.1`, and `http/app.ts` admits only loopback Host headers. There is also
no runtime-client credential, public gateway URL, gateway secret, controller ID,
or relay configuration in this checkout. Those are required design work, not
undocumented environment variables.
